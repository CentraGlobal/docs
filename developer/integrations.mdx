Use this page as the developer entry point for supported bridge integrations.

## API support

Integration management routes include:

- `GET /bridge-integrations/pms-presets`
- `GET /bridge-integrations`
- `GET /bridge-integrations/{id}`
- `POST /bridge-integrations`
- `PUT /bridge-integrations/{id}`
- `POST /bridge-integrations/{id}/import-reservations`
- `DELETE /bridge-integrations/{id}`
- `GET /bridge-api/integrations` for bridge-side lookup

Permissions:

- `integrations.read`
- `integrations.write`
- `integrations.delete`

## Example: list presets

`GET /bridge-integrations/pms-presets`

Example response:

```json
{
  "success": true,
  "message": "Supported PMS presets retrieved successfully",

```

## HotelRunner

Use HotelRunner when the integration follows the standard HotelRunner-compatible bridge flow.

Example create request:

`POST /bridge-integrations`

```json
{
  "name": "HotelRunner Primary",
  "integrationType": "channel_manager",
  "provider": "hotelrunner",
  "status": "active",
  "authConfig": {
    "hr_id": "HT-2321"
  },
  "metadata": {
    "reservation_event_enabled": true,
    "reservation_event_mode": "internal_and_external",
    "reservation_payload_format": "centra_v1"
  }
}
```

Example response:

```json
{
  "success": true,
  "message": "Integration created successfully",
  "data": {
    "id": "int_123",
    "hotelId": "HT-2321",
```

## Custom

Use custom integrations when the partner does not follow the HotelRunner contract and needs a manual callback definition.

Example create request:

`POST /bridge-integrations`

```json
{
  "name": "Custom PMS Adapter",
  "integrationType": "custom",
  "provider": "custom",
  "status": "active",
  "authConfig": {
    "username": "partner-user"
  },
  "metadata": {
    "pms_callback_source": "manual",
    "pms_preset_id": "custom",
    "pms_callback_method": "POST",
    "pms_callback_url": "https://partner.example.com/reservations/callback",
    "pms_callback_headers": {
      "Authorization": "Bearer token"
    },
    "pms_callback_body": {
      "reservation_id": "$integration.id",
      "hotel_id": "$hotel.id"
    }
  }
}
```

Example response:

```json
{
  "success": true,
  "message": "Integration created successfully",
  "data": {
    "id": "int_456",
    "hotelId": "HT-2321",
    "name": "Custom PMS Adapter",
    "integrationType": "custom",
    "provider": "custom",
    "status": "active",
    "authConfig": {
      "username": "partner-user"
    },
    "callbackUrl": null,
    "pmsConfigId": null,
    "metadata": {
      "pms_callback_source": "manual",
      "pms_preset_id": "custom",
      "pms_callback_method": "POST",
      "pms_callback_url": "https://partner.example.com/reservations/callback"
```
