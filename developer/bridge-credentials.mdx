---
title: "Bridge credentials"
description: "How developers obtain and use bridge credentials."
---

Use bridge credentials when a bridge-facing integration needs an authenticated token and a defined scope set.

## API support

Bridge credential routes include:

- `GET /bridge-credentials`
- `GET /bridge-credentials/{id}`
- `POST /bridge-credentials`
- `PUT /bridge-credentials/{id}`
- `DELETE /bridge-credentials/{id}`
- `GET /bridge-api/credentials` for bridge-side internal validation

Permissions:

- `bridge_credentials.read`
- `bridge_credentials.write`
- `bridge_credentials.delete`

## What a bridge credential contains

- where credentials come from
- scope and environment rules
- rotation process
- storage and security guidance

Typical credential fields include:

- `status`
- `scopes`
- `expiresAt`
- generated `token`

## Example create request

`POST /bridge-credentials`

```json
{
  "status": "active",
  "scopes": ["read:rooms", "write:inventory", "write:reservations"],
  "expiresAt": "2026-12-31T23:59:59.000Z"
}
```

Example response:

```json
{
  "success": true,
  "message": "Bridge credential created successfully",
  "data": {
    "id": "bc_123",
    "token": "bridge_live_abc123xyz",
    "hotelId": "HT-2321",
    "status": "active",
    "scopes": ["read:rooms", "write:inventory", "write:reservations"],
    "expiresAt": "2026-12-31T23:59:59.000Z",
    "createdBy": "usr_123",
    "createdAt": "2026-06-02T10:00:00.000Z",
    "updatedAt": "2026-06-02T10:00:00.000Z",
    "lastUsedAt": null
  }
}
```

## Example bridge-side validation request

`GET /bridge-api/credentials`

Example request headers:

```http
x-hotel-id: HT-2321
x-bridge-token: bridge_live_abc123xyz
```

Example response:

```json
{
  "success": true,
  "message": "Credential validated successfully",
  "data": {
    "id": "bc_123",
    "hotelId": "HT-2321",
    "token": "bridge_live_abc123xyz",
    "status": "active",
    "scopes": ["read:rooms", "write:inventory", "write:reservations"],
    "metadata": {},
    "expiresAt": "2026-12-31T23:59:59.000Z",
    "lastUsedAt": null,
    "createdBy": "usr_123",
    "createdAt": "2026-06-02T10:00:00.000Z",
    "updatedAt": "2026-06-02T10:00:00.000Z"
  }
}
```

<Warning>
  Treat the token like a secret. Store it securely and rotate it if exposure is suspected.
</Warning>
