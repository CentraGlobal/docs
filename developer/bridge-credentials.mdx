Use this page to document how bridge credentials are issued, scoped, rotated, and secured.

## API support

Bridge credential routes include:

- `GET /bridge-credentials`
- `GET /bridge-credentials/{id}`
- `POST /bridge-credentials`
- `PUT /bridge-credentials/{id}`
- `DELETE /bridge-credentials/{id}`
- `GET /bridge-api/credentials` for bridge-side internal validation

Permissions:

- `bridge_credentials.read`
- `bridge_credentials.write`
- `bridge_credentials.delete`
