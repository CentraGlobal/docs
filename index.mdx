## How to use this docs site

Choose the page type that matches your goal:

- **Product guides** explain the workflow in business terms
- **API support** sections show the endpoints behind the workflow
- **Examples** give you request and response payloads you can adapt quickly

## What this docs site covers

- product workflows by area
- API support for backend and bridge use cases
- integration setup and bridge credentials
- request and response examples for the main flows
- operator and developer guidance side by side
- coming-soon sections for PMS, OBE, and CRM

## Who this is for

- operators configuring Centra products
- integration teams using bridge callbacks and adapters
- developers who need direct API support and references

## Documentation principles

Use this space to keep guidance practical, current, and easy to scan.

- show the workflow first, then the API support behind it
- prefer examples that customers can adapt immediately
- document prerequisites, permissions, and expected outcomes clearly
- separate operator tasks from integration implementation guidance
