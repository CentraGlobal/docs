Use this page to document how to create room types in CRS.

## API support

Room type routes include:

- `GET /roomtypes`
- `GET /roomtypes/{id}`
- `POST /roomtypes`
- `PUT /roomtypes/{id}`
- `DELETE /roomtypes/{id}`

Permissions:

- `roomtypes.read`
- `roomtypes.write`
- `roomtypes.delete`

## Include

- required room type fields
- occupancy and capacity rules
- naming conventions
- status or activation behavior
