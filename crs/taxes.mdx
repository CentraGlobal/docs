Use this page to document how taxes are defined and applied.

## API support

Tax routes include:

- `GET /taxes`
- `GET /taxes/{id}`
- `POST /taxes`
- `PUT /taxes/{id}`
- `DELETE /taxes/{id}`

Permissions:

- `taxes.read`
- `taxes.write`
- `taxes.delete`

## Include

- tax type
- percentage or fixed amount
- scope of application
- how taxes appear in pricing and reservation totals
