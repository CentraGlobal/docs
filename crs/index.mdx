The CRS section covers the day-to-day setup workflows that define what you sell, how you price it, and how reservations are created.

Use these pages when you are preparing a property for sale, updating inventory, or handling a reservation from the CRS side.

## API support

These workflows map to backend API groups such as:

- `/roomtypes`
- `/cancellation-policies`
- `/taxes`
- `/rateplans`
- `/ari`
- `/availability`
- `/pricing`
- `/reservations`

Use the API support when you want to automate configuration, validate setup changes, or integrate the same CRS workflow into another system.

## Recommended setup order

1. Create room types
2. Create cancellation policies
3. Create taxes
4. Create rate plans
5. Load availability
6. Load rates
7. Create reservations
