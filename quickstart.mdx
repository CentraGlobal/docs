Use this guide when you want the fastest path from initial access to product-oriented documentation with API support.

## Prerequisites

Before you begin, make sure you have:

- access to the correct Centra workspace
- the product area you want to work on first
- access to backend and bridge API docs where needed

## Start by product area

Centra docs are organized by product. Each product page should help readers understand both the workflow and the API capabilities behind it.

## Recommended path

<Steps>
  <Step title="Choose the product area">
    Start with **Auth**, **CRS**, **Bridge**, or **Developer** depending on your goal.
  </Step>

  <Step title="Follow the workflow guide">
    Read the page for the task you want to complete, such as creating room types, loading availability, or setting up bridge credentials.
  </Step>

  <Step title="Use the linked API support">
    For every documented workflow, use the linked API capability to automate, validate, or integrate the same process.
  </Step>

  <Step title="Open the reference docs when needed">
    Use backend `/docs` and bridge `/docs` to inspect the generated OpenAPI documentation for exact request and response details.
  </Step>
</Steps>
