Use this page to document the HotelRunner adapter endpoints, authentication, request models, and response expectations.

## API support

HotelRunner-compatible routes include:

- `GET /v2/apps/rooms`
- `PUT /v2/apps/rooms/~`
- `PUT /v2/apps/rooms/daily`
- `GET /v2/apps/reservations`
- `PUT /v2/apps/reservations`
- `PUT /v2/apps/reservations/~`
- `PUT /v2/apps/reservations/fire`

Authentication is handled through HotelRunner-style query parameters such as `hr_id` and `token`.

## Example: get rooms

`GET /v2/apps/rooms?hr_id=HT-2321&token=bridge-token`

Example response:

```json
{
  "rooms": [
    {
      "rate_code": "HR:1",
      "inv_code": "HR:1",
      "availability_update": true,
      "restrictions_update": true,
      "price_update": true,
      "pricing_type": "guest_based",
      "name": "Standard Room",
      "description": "Standard Room Description",
      "policy": "Standard Room Policy",
      "room_capacity": 3,
      "adult_capacity": 2,
      "is_master": false,
      "shared": false,
      "channel_codes": ["bookingcom", "online"],
      "sales_currency": "EUR",
      "sell_online": true

  ]
}
```

## Example: update inventory

`PUT /v2/apps/rooms/~?hr_id=HT-2321&token=bridge-token&inv_code=HR:1&start_date=2026-07-01&end_date=2026-07-05&availability=10&price=1450`

Example response:

```json
{
  "status": "ok",
  "transaction_id": "1735228800000-0"
}
```

`GET /v2/apps/reservations?hr_id=HT-2321&token=bridge-token&page=1`

Example response:

      "channel": "online",

`PUT /v2/apps/reservations?hr_id=HT-2321&token=bridge-token&message_uid=bda9c306bd790e022afc107a8a816966`
