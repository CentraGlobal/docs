The Bridge section covers how Centra receives reservations and exposes adapter APIs.

## API support

Bridge capabilities are split between:

- backend bridge management routes such as `/bridge-credentials`, `/bridge-integrations`, and `/bridge-api/*`
- bridge service endpoints used for partner-facing connectivity
- generated Swagger docs under `/docs` and OpenAPI JSON under `/doc`
