Use this page to document custom adapter patterns for non-HotelRunner integrations.

## API support

Custom channel routes include:

- `POST /roominventory/update`
- `POST /reservations/confirm`
- `POST /reservations/push/{token}/{hotel_id}`

These routes support XML-first integrations and authenticated callback flows for custom or LTA-style partners.
